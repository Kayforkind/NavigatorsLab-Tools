Suite automation for humans — and for machines

Every tool is scriptable. Drive them from an AI agent with a Model Context Protocol endpoint, or with plain parameterized URLs — the same pages, the same privacy: files stay on the device running the browser.

MCP endpoint

JSON-RPC 2.0 at POST /tools/mcp — initialize, tools/list, tools/call. Compute tools: catalog, QR payloads, text diff, text stats. Stateless, no auth, protocol 2025-06-18.

Deep links with parameters

Every page accepts a strict allow-list of URL params — qr.html?text=… renders instantly, shrink.html?url=…&targetKB=300 pre-loads and pre-sets. ?url= is same-origin only, enforced in code.

Machine-readable docs

llms.txt + llms-full.txt at the site root, tools.json as data, and a full reference page — so an agent can discover and drive the whole suite without a human.

Read the Agent Mode docs → curl example: {"jsonrpc":"2.0","id":1,"method":"tools/list"} → POST /tools/mcp

Questions people actually ask

If there's no server… where does the processing happen?

In your browser tab, on your device. Each tool is a static page with JavaScript that reads your file into memory, processes it with Web APIs (Canvas, Web Audio, WASM), and offers the result as a download. Close the tab and it's gone.

Can you see my files? Is there a log?

No, and no. There is no upload endpoint, no queue, no storage bucket — nothing that could receive a file. The security suite proves this on every release: it loads every page, watches every network request, and asserts that nothing goes anywhere but this site.

What's the catch? Is there a premium tier?

No catch, no tier, no watermark, no "upgrade to unlock bigger files." MIT licensed — take the code and self-host it if you like. The only limit is your device's memory.

Does it work offline?

Yes — after your first visit, the service worker precaches every page and engine (including the 24 MB OCR model). A test literally turns the network off and runs a tool to prove it.

Who made this?

NavigatorsLab — a lab for local-first, private-by-default software. The suite's big sibling is PDF Studio, a full in-browser PDF editor.

Privacy isn't a promise here. It's the architecture.

These are static pages. There is no server that could receive your files — no upload endpoint, no queue, no storage bucket, no analytics, no cookies, no accounts.

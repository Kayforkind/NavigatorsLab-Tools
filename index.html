01 · 🤖 For AI agents, too

Suite automation for humans — and for machines

Every tool is scriptable. Drive them from an AI agent with a Model Context Protocol endpoint, or with plain parameterized URLs — the same pages, the same privacy: files stay on the device running the browser.

MCP endpoint

JSON-RPC 2.0 at POST /tools/mcp — initialize, tools/list, tools/call. Compute tools: catalog, QR payloads, text diff, text stats. Stateless, no auth, protocol 2025-06-18.

Deep links with parameters

Every page accepts a strict allow-list of URL params — qr.html?text=… renders instantly, shrink.html?url=…&targetKB=300 pre-loads and pre-sets. ?url= is same-origin only, enforced in code.

Machine-readable docs

llms.txt + llms-full.txt at the site root, tools.json as data, and a full reference page — so an agent can discover and drive the whole suite without a human.

agent-mode — try it
# list every tool the suite exposes to agents
curl -s -X POST https://navigatorslab.com/tools/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | jq '.result.tools[].name'

05 · The guarantee

Privacy isn't a promise here. It's the architecture.

These are static pages. There is no server that could receive your files — no upload endpoint, no queue, no storage bucket, no analytics, no cookies, no accounts. We keep no attachments and no user information, ever. Open devtools → Network, load any tool, and watch it stay silent after the initial load. The single exception is deliberate and user-initiated: the Password Breach Checker sends only the first 5 characters of your password's SHA-1 hash to Have I Been Pwned when you press Check — the password itself never leaves your device.

CSP: default-src 'none' · script-src 'self' · connect-src 'self' (+ api.pwnedpasswords.com, breach checker only, only on Check)
